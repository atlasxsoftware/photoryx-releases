# PHOTORYX — downloads

**PHOTORYX by Atlas X Software**: editor de imagens para Windows.

Baixe o instalador mais recente em **[Releases](https://github.com/atlasxsoftware/photoryx-releases/releases/latest)**
(`PHOTORYX-Setup-x.y.z.exe`).

Depois de instalado, o PHOTORYX se atualiza sozinho. O arquivo [`update.json`](update.json) informa
a versão mais nova e a versão mínima aceita.
